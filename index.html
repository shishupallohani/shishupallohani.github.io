About

About Me

Backend Engineer with 4+ years of experience building scalable, resilient backend systems using Java and Spring Boot. I work on distributed architectures and cloud-ready microservices, focused on code that doesn't just work — but scales. Currently building and maintaining backend services for **ICMS**, an enterprise-scale Insurance Core Management System — a multi-portal claims processing ecosystem serving Corporate, Member, Insurer, and Provider stakeholders. My day-to-day includes designing secure REST APIs and implementing authentication using JWT and Keycloak (OAuth2). My core stack: Spring Boot, Spring MVC, Spring Security, Hibernate/JPA, JDBC with Oracle and MySQL. I use Feign Client for inter-service communication, Eureka for service discovery, and a centralized Config Server for environment management. For resilience, I implement Circuit Breaker and Retry patterns via Resilience4j — critical when a single failing service can't be allowed to cascade through an active claims flow. Redis handles distributed caching to cut repeated DB hits on high-frequency lookups, and all APIs are documented via Swagger/OpenAPI. On the infrastructure side, I containerize with Docker, deploy on Kubernetes, and automate builds and rollouts through Jenkins CI/CD pipelines. Production visibility comes from Prometheus and Grafana metrics with centralized logging — because knowing *why* something broke matters as much as fixing it. I also have hands-on AWS exposure (EC2, S3). What drives me is solving hard distributed-systems problems — keeping services fast, secure, and available as transaction volumes scale — and continuously learning the next tool or pattern that gets us there.
